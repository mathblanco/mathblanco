## Featured Projects

### 1. Image Clustering
**Computer Vision | Unsupervised Machine Learning**

A Streamlit application that applies cluster analysis to image pixels, identifying visual patterns and grouping similar regions through unsupervised learning techniques.

The broader goal is to evolve this project into an image recognition framework, providing a foundation for feature extraction, pattern identification, and more advanced image analysis capabilities.

- **Tech Stack:** Python, Scikit-learn, Streamlit, NumPy, OpenCV.
- **Repository:** [Image Clustering](https://github.com/mathblanco/image-clustering)

### 2. Financial Anomaly Detection & Market Analytics Dashboard
**Machine Learning | Financial Analytics**

An interactive web application developed in R using the Shiny framework, featuring an automated Machine Learning pipeline for financial market analysis.

- **Key Features:** Trains an Isolation Forest model on-the-fly to detect and visualize anomalies in historical price data for user-selected assets. Includes interactive time-series plots, dynamic filtering, and market insights.
- **Tech Stack:** R, Shiny, `isotree`, `shinydashboard`, `tidyverse`, `plotly`.
- **Live Demo:** [Access the Application](https://careca.shinyapps.io/dataScience/)

### 3. Automated Time Series Forecasting App
**Machine Learning | Time Series Forecasting**

A web application built with R Shiny that enables end-to-end time series forecasting using Machine Learning without requiring programming knowledge.

- **Key Features:** Users can upload historical datasets, configure parameters, and train a K-Nearest Neighbors (KNN) model to generate forecasts and interactive visualizations.
- **Tech Stack:** R, Shiny, `tsfknn`, `caret`, `tidyverse`, `plotly`, `shinydashboard`.
- **Live Demo:** [Access the Application](https://careca.shinyapps.io/forecastMachine/)
